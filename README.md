# Moony Have
> Cool 2D Game

This is 2D platformer game with fun controls and mechanics. The graphics of the game are like hand drawn pixelart stuff. The game is fully expandable.
I am adding new things everyday. The main goal will be to collect all the stars hidden all around the map. There will be enemies to fight with too and some powerups.

### You Can Play The Latest Exported Version of Game on itch.io: https://slayerarman.itch.io/moony-haven

Download Those Files and Open the project in Godot to Remix the game with your new ideas.
